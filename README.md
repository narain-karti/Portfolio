# Narain Karti — Engineering & Research Portfolio

Personal engineering, research, and venture portfolio built with Next.js 15 (App Router + Turbopack), React 19, Framer Motion, and an isometric SVG Hairline engine.

## Overview

- **Home (`/`)** — Responsive single-viewport (`100dvh`) Bento portal with fast skippable entrance animation and direct click-through cues.
- **Projects (`/work`)** — 10 featured builds (**DATADOC**, **Project-MELV**, **Otomo**, **MECH-G**, **Project K**, **Elio**, **Quorum**, **DECEPTRIX**, **Beyond Earth**, **AxoWeb Systems**) with deep-linked architecture dossiers (`?project=<id>`).
- **Knowledge Graph (`/graph`)** — Interactive topology linking pages, domain hubs, projects, and engineering write-ups.
- **Engineering Logs (`/blog`)** — Commit-history build journals documenting bottlenecks, tradeoffs, and fixes.
- **Experience & Stack (`/builder`)** — Ventures, internships, campus leadership, awards, and interactive Quorum Dialectic Ring.
- **About (`/about`)** — Story, dual IIT Madras × NIAT degrees, academic honors, and adopted isometric Terminal Rig (`/hairline-adopt`).
- **Research & Labs (`/website`)** — Investigation tracks, research-to-product methodology, and interactive Hairline workbench.
- **Resources & CV (`/downloads`)** — Downloadable PDF résumé, `datadoc-cli` PyPI command, live venture links, and standalone HTML artifacts.
- **Connect (`/contact`)** — Collaboration tracks, direct email copy, and social links.

## Development & Production

```bash
npm install
npm run dev      # Next.js 15 with Turbopack
npm run build    # Static + SSG production build
npm run start    # Serve production build
```

Compatible with zero-config deployment on Vercel (`framework: nextjs`).
